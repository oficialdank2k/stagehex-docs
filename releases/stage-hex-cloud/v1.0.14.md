# Versão 1.0.14

### Geral

⭐ Sincronização de Biblioteca - Sistema completo de sincronização de modelos 3D do servidor para o SketchUp

⭐ Auto-Update da Biblioteca - Biblioteca atualizada automaticamente com os últimos modelos disponíveis

⭐ Instalação Automática de Atualizações - Nova opção no menu de sistema para habilitar/desabilitar atualizações automáticas

⭐ Barra de Progresso Combinada - Indicador visual para acompanhar instalação de plugin e biblioteca

⭐ Terminologia Inteligente - Interface mostra "Instalando" para primeira instalação e "Atualizando" para atualizações

⭐ Notificações Combinadas - Alertas agrupados quando há atualizações de plugin e biblioteca disponíveis

⭐ Página de Configurações Melhorada - Botões inteligentes que se adaptam ao status de instalação atual

⭐ Detecção Inteligente de Versões - Sistema otimizado para identificar atualizações disponíveis
