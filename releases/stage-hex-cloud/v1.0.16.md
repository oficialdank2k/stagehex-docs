# Versão 1.0.16

### Geral

⭐ Monitor de Processos do SketchUp - Sistema detecta automaticamente quando o SketchUp é aberto

⭐ Notificações de Autorização - Alerta nativo do Windows ao autorizar o SketchUp para uso com assinatura válida

⭐ Detecção de Múltiplas Versões - Monitoramento de todas as versões do SketchUp instaladas no sistema

⭐ Mensagens Nativas do Windows - Alertas integrados com o sistema Windows para melhor experiência

⭐ Proteção Durante Atualizações - Detecta se SketchUp está aberto e previne corrupção de arquivos durante atualizações

⭐ Alertas de Permissão - Notificações claras quando o Depence precisa de permissões de administrador

⭐ Página de Configurações Melhorada - Interface mais limpa e organizada para facilitar o uso

⭐ Aplicação Mais Rápida - Melhorias internas que tornam a aplicação mais ágil e responsiva
