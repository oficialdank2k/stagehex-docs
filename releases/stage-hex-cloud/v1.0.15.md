# Versão 1.0.15

### Geral

⭐ Detecção Automática do Depence3 - Sistema reconhece automaticamente Depence3 instalado no computador

⭐ Sincronização com Depence3 - Biblioteca de fixtures sincronizada automaticamente com Depence3

⭐ Priorização Inteligente de Versões - Sistema detecta e prioriza versões do Depence na ordem: 4 > 3 > 2

⭐ Desinstalação da Biblioteca - Nova opção para remover biblioteca do Depence3 durante desinstalação completa

⭐ Limpeza Automática - Sistema de limpeza inclui remoção de arquivos do Depence3 quando necessário
