# Versão 1.0.13

### Compatibilidade

{% hint style="info" %}
Esta é a primeira versão pública oficial do StageHex Cloud. Todas as funcionalidades principais estão implementadas e testadas. Versões futuras trarão melhorias incrementais e novos recursos.
{% endhint %}

### Geral

⭐ Gerenciamento de Plugins - Instalação e atualização automática do plugin StageHex para SketchUp

⭐ Biblioteca de Modelos 3D - Acesso a mais de 150 modelos profissionais de iluminação cênica

⭐ Sincronização com Depence - Integração automática com Depence3 para biblioteca de fixtures

⭐ Sistema de Auto-Update - Atualizações automáticas com download em segundo plano

⭐ Gerenciamento de Dispositivos - Controle de dispositivos autorizados com limite de licença

⭐ Interface intuitiva, limpa e moderna para gerenciar tudo em um só lugar

⭐ Notificações de atualização integradas alertando quando há novas versões disponíveis

⭐ Opção de desinstalação completa que remove todos os componentes instalados

⭐ Aplicação rápida e leve com carregamento ágil e uso eficiente dos recursos

⭐ Sistema de Diagnóstico - Registros automáticos para melhor suporte quando necessário

⭐ Sistema de Licença Seguro com proteção robusta para uso autorizado

⭐ Melhorias de segurança para proteger seus dados e informações

⭐ Manutenção de Login - Sessão permanece ativa ao gerenciar dispositivos

⭐ Controle de Acesso - Recursos disponíveis conforme seu plano de assinatura

🪲 Preservação de Preferências - Configurações do usuário mantidas durante operações do plugin

🪲 Download em Produção - Corrigido problema de download do plugin em ambiente de produção

🪲 Caminhos do Depence - Sincronização automática ao trocar versões do Depence

🪲 Acesso ao Depence - Resolvido problema de acesso aos arquivos do Depence

🪲 Exibição da Aplicação - Corrigido problema que causava tela branca em alguns computadores

🪲 Compatibilidade do Windows - Melhorada a compatibilidade com diferentes versões do Windows
